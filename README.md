# 💰 Personal Finance Tracker
A modern **frontend-based finance tracker** to manage income and expenses with analytics, filters, and data visualization.
## 🚀 Live Demo
https://abhishekkumar2007.github.io/Personal_Finance_Tracker/
---
## ✨ Features
* ➕ Add income & expenses
* ✏️ Edit & 🗑️ delete transactions
* 📊 Dashboard (Income, Expense, Balance)
* 🔍 Search transactions
* 📅 Filter (Income / Expense / Monthly / Date Range)
* 📂 Export data as CSV
* 🧮 Real-time balance calculation
* 💾 Data stored using browser localStorage
* 📱 Fully responsive design
---
## 🛠️ Tech Stack
* HTML5
* CSS3 (Glassmorphism UI)
* JavaScript (Vanilla JS)
* 📊 Chart.js (for data visualization)
